# Teacher-Hub — Use Cases (Judge + Team Brief)

**Product:** AI teaching loop for **Grades 4–6 Math**  
**Core loop:** Diagnose → Find gap → Generate worksheet → Grade → Adapt level  
**Repo:** https://github.com/SabioTechTeam/Teacher-Hub  
**One-liner:** Khan picks the next problem from a library. We *write* the next problem from a live student model.

---

## Why use cases matter
The tech is a means. The product wins if a real person has a painful moment and we clearly fix it.

---

## Beachhead (prove this weekend)

### UC-1 — Stuck student, same night / same period  ★ PRIMARY
**Who:** Grades 4–6 student confused on one fraction skill  
**When:** After class, homework time, tutoring, or independent work  
**Job to be done:** Get unstuck without waiting for a parent/teacher to invent practice  
**Flow:** Short quiz → gap skill + level → generated worksheet → grade → level adjusts  
**Success:** In under ~5 minutes, student practices the *right* skill at the *right* difficulty  
**Demo:** Show this end-to-end

---

## Expansion use cases (story now, build next)

### UC-2 — Student ahead / bored
Same loop; high score → harder items / next skill on the prerequisite graph.  
**Job:** Stay challenged without teacher hand-writing enrichment.

### UC-3 — Class warm-up or exit ticket
Whole class runs a micro-check; each student gets differentiated follow-up practice.  
**Job:** Differentiate 28 kids without 28 photocopied packets.

### UC-4 — Teacher “Why is Sarah stuck?”
Evidence: gap skill, likely misconception, what to try next. Teacher approves high-stakes moves.  
**Job:** Turn gut feel into a next action in seconds (PLC, RTI, parent talk).

### UC-5 — Catch-up after absence
Quiz maps missing prerequisites; generated path fills holes before new content.  
**Job:** Re-enter class without public embarrassment.

### UC-6 — Calm, accessible practice (incl. many neurodivergent learners)
Predictable flow, pace control, multi-modal explanation (visual / steps / story), low social pressure.  
**Job:** Accessible practice — **not** diagnosis or treatment of autism/disabilities.  
**Guardrail:** We personalize practice; we do not label or diagnose. Teachers stay in charge.

## Explicit non-goals (this weekend)
- Full K–12 OS / every subject  
- Parent social network  
- Diagnosing disabilities or IEPs automatically  
- Beating Khan on content library size  

---

## vs Khan Academy (use-case lens)
| | Khan | Teacher-Hub |
|--|------|-------------|
| Core job | Learn from a rich catalog + mastery path | Unstick *this* learner *now* with generated practice |
| Personalization | Next item from library / mastery | Diagnose + author items + adapt from outcomes |
| Teacher role | Assign / monitor catalog | AI teaching teammate; teacher owns high-stakes calls |
| Moat over time | Content + brand | Student model + strategy effectiveness + teacher workflow |

---

## Hook → long-term
**Hook:** Painful, frequent moment — stuck on one skill with no matching practice.  
**Long run:** Every attempt improves the student model (mastery, misconceptions, what strategies worked). Product gets smarter with use → teaching OS for classroom scale.
